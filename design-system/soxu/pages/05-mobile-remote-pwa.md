# 05 · Daemon 内嵌响应式移动 Web/PWA 遥控端规范 (`apps/mobile-web`)

> **继承主规范**：[`../MASTER.md`](../MASTER.md)  
> **目标模块**：`apps/mobile-web`（TypeScript + React 19 + shadcn/ui + Tailwind CSS v4，经 `rust-embed` 内嵌进 `soxu-daemon`）  
> **参考对标**：`padu`（窗口宽度自适应 13 组设备矩阵、安全区与 200% 字号） + `paseo`（`#offer=` 配对链接、手机端审批与 Steer 遥控）

---

## 一、产品定位：桌面工作台的「随身遥控舱」，而非缩水版 IDE

用户在离开电脑（通勤、沙发、会议间隙）时打开手机主屏幕上的 **Soxu Remote PWA**，核心诉求高度聚焦在 **30 秒内完成三件事**：
1. **看全局**：哪几个 Worktree 里的 Agent 跑完了、卡住了、还是正在等我批权限？
2. **批权限**：看清待执行命令或关键代码 Diff，大拇指单手一键「允许一次」或「拒绝并口述/打字纠偏」。
3. **发指令**：向正在跑的 Agent 投递 `Steer`（中途纠偏）、`Queue`（排队下一件事），或启动 `check-all` 验证脚本。

> **性能与体积硬指标**：首屏关键 JS + CSS Gzip 总包体 **`< 35 KB`**，局域网 / Tailscale / 中继弱网下首屏可交互时间（TTI）**`< 400ms`**，默认采用 **Pure Black (`#000000`)** 最大化手机 OLED 续航。

## 二、唯一窗口宽度自适应架构（Window-Width Adaptive Matrix）

严格执行 **「只响应实时窗口宽度 `window.innerWidth`，绝不检测设备型号或锁定屏幕方向」** 准则：

```text
[compact: < 640px 手机 / 小折叠外屏 / iPad 1/3 分屏]
┌─────────────────────────────┐
│ [◧] Soxu   [🔍 搜索]  [⊞◐⚙◨]│ 浮动毛玻璃顶栏（三轨不重叠，左右可唤起抽屉）
├─────────────────────────────┤
│ ⚠️ 待审批 (1) · feat/m2-cli │ 置顶高优审批横幅 (一键直达)
│ [查看命令与 Diff]  [批准]   │
├─────────────────────────────┤
│                             │
│    当前选中会话流 / 列表     │ 单栏全出血或 16px 页边距
│    (#000000 Pure Black)     │
│                             │
├─────────────────────────────┤
│ [快捷片: 先跑测试] [总结]   │
│ ┌─────────────────────────┐ │
│ │ 输入指令 (16px)... [⚡] │ │ 三态遥控输入舱 (#212121)
│ └─────────────────────────┘ │
│ [工作区]  [会话]  [待批①] [脚本] │ 底部 4 栏导航 (避让 safe-area-bottom)
└─────────────────────────────┘
```

- **窄屏左右双抽屉原则**：在窗口宽度 `< 1024px` 时，左栏「快速对话与项目工作树」与右栏「变更对比 / 受管脚本与定时巡检」一律收进左右滑出抽屉（`Sheet side="left"` / `Sheet side="right"`）而非并排平铺，确保 `Soxu` 品牌标、顶栏按钮与居中搜索条在窄至 `320px` 视口下绝不重叠或产生页面水平滚动条。

[wide: ≥ 1024px 平板横屏 / 折叠大屏桌面模式 / 桌面浏览器]
┌──────────────────┬──────────────────────────────────────────┐
│ 左轨 320px       │ 右侧主会话与审阅画布 (居中限宽 760px)     │
│ (#0D0D0D)        │ (#000000 Pure Black)                     │
│ • 待审批置顶卡   │ • 顶栏工作区信息 + 游标同步状态          │
│ • 工作区/会话树  │ • 完整消息流 + 内联折叠 Diff + 审批卡     │
│ • 脚本与调度入口 │ • 底部 720px 三态悬浮输入舱              │
└──────────────────┴──────────────────────────────────────────┘
```

### 2.1 完整 13 组窗口视口自适应检验矩阵（Required Matrix，参考 `padu`）

| 典型场景 | 窗口宽×高 (px) | 尺寸分类 (`SizeClass`) | 布局与抽屉自适应规则 |
| :--- | :---: | :---: | :--- |
| **iPad 1/3 分屏** | `320 × 1180` | `compact` | 全单栏；操作胶囊自动换行，严禁产生水平滚动条；按钮命中 ≥ 44px |
| **小折叠外屏** | `344 × 882` | `compact` | 顶栏双行压缩为单行路径省略；输入舱保留基础发送与审批操作 |
| **iPhone SE 小屏** | `375 × 667` | `compact` | 垂直紧凑间距，对话流留足安全区滚出空间 |
| **主流手机竖屏** | `393 × 852` | `compact` | 底部 4 栏导航（工作区 / 会话 / 审批 / 脚本）；选择器统一走 Bottom Sheet |
| **大折叠展开（外/半幅）** | `412 × 882` | `compact` | 即使折叠屏已展开，只要 `width < 640px` 仍走 `compact` |
| **手机横屏** | `852 × 393` | `regular` ⚠ | 极短视口！底部输入舱自动收窄至单行 `minHeight`，Bottom Sheet 上限 `72dvh` |
| **折叠屏半折桌面态** | `840 × 480` | `regular` ⚠ | 严禁检测铰链角度；按 `regular` 单栏限宽居中 + 动态高度抽屉适配 |
| **折叠屏内屏展开** | `840 × 900` | `regular` | 单栏居中（消息 `760px` / 输入舱 `720px`） |
| **iPad 竖屏** | `820 × 1180` | `regular` ⚠ | 单栏居中限宽；仍使用 Bottom Sheet 而非强行弹出偏狭的双栏 |
| **iPad 13 寸竖屏 / 横屏** | `1024 × 1366` / `1180 × 820` | `wide` | 启用左轨 `320px` + 右侧居中对话画布（`max-w: 760px`）并排，隐藏底部 4 栏导航 |
| **Android 自由分屏** | 任意实时宽高 | 实时重算 | 只监听 `resize` 实时 `innerWidth`，拖拽分屏线瞬间平滑切换分类 |
| **200% 系统无障碍字体缩放** | 任意尺寸 | 全分类 | **严禁使用固定像素 `height` 包裹文本**，容器全部改用 `min-height` + `line-height` 弹性伸展 |

### 2.2 底部抽屉（Bottom Sheet）交互与键盘焦点守则
- **高度分级**：短选择器（CLI/模型/思考等级/权限）采用 `max-height: 56dvh`；高信息密度抽屉（Diff 审阅、扫码配对、历史会话导入、Checkpoint 回退）采用 `max-height: 76dvh`，顶部统一配 `36×4px` 中性灰拖拽条（`#383838`）与右上角关闭 `×`（命中区 `44×44px`）。
- **无障碍焦点与安全区**：打开抽屉瞬间背景加 `rgba(0,0,0,0.76)` 遮罩（`zIndex.modalScrim`），`Esc` 键优先关闭抽屉，关闭后焦点精准还原至原触发按钮；底部操作区统一叠加强制底部安全区 `env(safe-area-inset-bottom)`；外接 iPad 实体键盘时不生成虚假底部空白占位。

## 三、四大移动端核心交互流规范

### 3.1 零摩擦扫码配对与断线游标增量追平（Pairing & Seq Catch-up）
1. **扫码一键建连**：
   - 桌面端生成带一次性令牌与守护进程指纹的 URL（`http://<lan-or-tailscale-ip>:7698/#offer=<base64url>`），手机系统相机扫码打开浏览器后自动完成握手，将访问凭据存入本地安全存储并清除地址栏 `#offer=` 片段（防止截屏泄露令牌），同时引导「添加到主屏幕」以独立全屏 PWA 运行。
   - **手动降级路径**：无摄像头权限或远程浏览器环境下，同一屏幕直接提供「输入服务地址 + 6 位一次性配对码 / 访问令牌」表单（允许密码管理器粘贴）。
2. **锁屏唤醒增量追平（Cursor Catch-up Toast）**：
   - 手机切后台或锁屏重连后，客户端携带本地 `last_applied_seq` 请求增量事件流；
   - 追平期间顶栏展示非阻塞细进度条，完成后轻提示 `⚡ 已同步离线期间的 12 条更新 (seq #1044 → #1056)`，不闪烁清空已有对话 DOM。

### 3.2 大拇指友好的「待审批收件箱」（Thumb-Zone Approval Cards）
- 在手机单手握持姿势下，顶部难够到而屏幕中下部最易触达：
  - 当切换到「审批箱」或会话流底部出现权限审批卡时，审批操作按钮固定在卡片底部且高度 **`48px`**，按钮间水平间距 **`10px`**（杜绝误点相邻按钮）：
    - 左按钮：`[拒绝 / 留言]`（`#262626` 底 + `#ECECEC` 字）
    - 右主按钮：**`[允许一次 ✓]`**（`#FFFFFF` 纯白底 + `#000000` 纯黑粗体字，高风险命令时切换为需二次确认的绯红描边按钮）
  - 审批卡支持一键展开查看涉及修改的文件名与精简 Diff（默认折叠前 30 行关键差异，避免撑爆手机小屏）。

### 3.3 移动端三态遥控输入舱与快捷指令片（Quick Steer Chips）
- 手机打字成本高于桌面，因此在输入舱上方提供一行可横向轻扫的 **场景化快捷指令片**（高 `30px` 胶囊，点击直接填入或一键作为 `Steer` 发出）：
  - 运行中默认展示：`[⚡ 先跑 check-all 别急着提交]` · `[⚡ 遇到破坏性操作先停下汇报]` · `[⏳ 完成后更新 PROGRESS.md]`
  - 空闲/刚完成默认展示：`[总结本轮改动与风险]` · `[运行全工作区测试]` · `[生成 Git Emoji 提交预览]`
- 输入舱右侧清晰提供 `排队 (Queue)` / `纠偏 (Steer)` / `打断 (Stop)` 模式切换开关，触感与桌面端 100% 一致。

### 3.4 远程脚本与定时任务巡检页（Scripts & Schedules）
- 在手机端「脚本/系统」视图中，汇总展示：
  1. **守护进程与 Magpie 协同健康卡**（实时连接状态、协议版本 `v1`、Magpie `MagpieManaged` / `StandaloneNative` 模式）；
  2. **Workspace Scripts 遥控开关**（查看 `daemon-dev`、`mobile-dev`、`check-all` 最近一次退出码、耗时与尾部 20 行日志，支持远程一键重跑 `check-all`）；
  3. **Schedules & Heartbeats 概览**（查看定时巡检任务下次触发时间、暂停/恢复开关与未读失败角标）。

## 四、Oryn 移动端架构与全形态自适应增补规范（SinkLayout / DockPill / 折叠屏 / 触控安全）

1. **`SinkLayout` 下沉式侧栏与底层 `52px` 分区胶囊**：
   - 在常规竖屏手机（`< 640px` 且视口高 `> 500px`）中取消传统固定占屏的常驻底部导航栏，改用 `SinkLayout`；
   - 主对话卡片平时覆盖整个屏幕（最大纵深留给对话与输入）；左滑（`clientX <= 24px` 右拖 `> 60px`）或点击左上菜单键将主卡片向右推移 `min(84vw, 316px)` 并呈现圆角描边，底层露出完整工作区侧栏及底部 `52px` 四分区胶囊（`会话` / `收件箱(角标)` / `脚本` / `设置`）；开启时主卡片自动施加 `inert`，按 `Esc` 或点击卡片右缘条关闭并精准还原焦点。
2. **上滑/点击收起输入舱为 `40px` `DockPill` 与回到底部浮动胶囊**：
   - 输入舱顶部设细腻折叠握把：用户向下滑动（`dy > 28px`）或轻点可将整个输入舱收起为 `h = 40px` 紧凑胶囊 **`DockPill`**（展示活跃 Agent 图标、运行脉冲点与待发队列数量），上滑或轻点即可瞬间恢复并聚焦文本域；
   - 滚动正文距底部超出 `80px` 时浮现 **`回到底部`** 悬浮按钮。
3. **折叠屏双段窗口与短横屏布局（`useAdaptiveViewport` + VisualViewport）**：
   - **左右双屏展开 (`dual-horizontal` / `viewport.segments` 或 `?fold=dual-h` 与外观设置预览)**：左屏承载对话流与输入舱，右屏常驻多文件 Diff / Artifact / Scripts 检查器，中间留出 `>= 12px` 铰链安全隔离槽，绝不把按钮或文字跨在折叠缝上；
   - **手机横屏 (`height <= 500px`) 与半折悬停 (`dual-vertical`)**：右侧/底部切换为左缘固定 **`52px` 紧凑图标轨**（释放垂直阅读区），半折悬停态进一步按上下物理段分隔对话流与输入区；
   - **软键盘与气泡对比度**：根视图实时绑定 `window.visualViewport` 键盘差值至 `--soxu-kb-inset`，配合 `.soxu-kb-pad` 自动顶起输入舱；用户发送气泡使用 `bg-[var(--soxu-surface-raised)] border-[var(--soxu-border-subtle)]`，确保纯黑/纯白模式下高对比清晰可读。
4. **触控手势与超窄防溢出（`320px` + `pointer: coarse`）**：
   - 底部 `Sheet` 顶部抓手区支持向下拖拽超出 `72px` 直接滑关；
   - 当视口 `< 400px`（iPad 1/3 分屏 `320px`、外屏 `344px`）时自动将配对/收件箱收纳至 `HoverExpandDock` 并简并思维强度按钮入 Sheet，确保顶栏与输入舱工具条永远单屏居中不越界、无横向滚动条。
