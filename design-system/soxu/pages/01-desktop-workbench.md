## 二、左栏：无项目快速对话、项目文件夹 → 工作树层级与归档区

1. **无项目快速对话区（Quick Chat）**：位于左栏最顶部，支持不绑定任何本地磁盘仓库或 Git 项目即可直接与任意代理自由对话（用于技术咨询、方案推演与通用问答），支持一键新建与归档。
2. **项目文件夹 → Worktree 二级树**：
   - **一级节点（项目文件夹）**：展示文件夹图标、项目名称、脱敏根目录路径与项目级状态聚合，支持折叠/展开与右侧 `+` 按钮新建隔离工作树；
   - **二级节点（工作树与主干）**：在所属项目文件夹下带 `12px` 左侧树状缩进导引线排列，清晰展示当前仓库下的本地主工作区与各 `worktree` 隔离分支。
3. **状态桶聚合与排序规则（Workspace State Buckets）**：

| 优先级 | 状态桶枚举 | 视觉指示器（圆点 + 色彩双编码） | 触发条件 |
| :---: | :--- | :--- | :--- |
| **P0 (最高)** | `needs_input` | 琥珀实心圆点 `#F59E0B` + 右侧胶囊数字 `[待批]` | 存在待人工确认的权限审批或提问卡 |
| **P1** | `failed` | 绯红圆点 `#EF4444` + `[失败]` | 存在未读异常退出或脚本崩溃 |
| **P2** | `running` | 电光蓝呼吸圆点 `#3B82F6` + 耗时秒表 | 主代理或子代理正在流式运行 |
| **P3** | `attention` | 翠绿实心圆点 `#22C55E` + `[新完成]` | 后台回合完成待查 |
| **P4 (最低)** | `done` / `idle` | 中性灰圆点 `#8E8E8E` | 所有会话空闲且已读 |

4. **已归档对话折叠区（Archived Drawer）**：位于左栏底部，支持将已完成的历史快速对话或工作树会话一键归档收起，亦可随时展开恢复至活跃列表。

## 三、中栏顶区：可关闭/归档会话页签、前置状态圆点与子代理轨道

1. **主会话标签栏（Session Tab Strip，高 `36px`）**：
   - **去掉标签顶部 2px 绿色横条**，统一在标签文字最前方放置 **`8×8px` 语义颜色状态小圆点**（运行中电光蓝、待确认琥珀、失败绯红、新完成翠绿、空闲中性灰）直观区分运行态；
   - **页签弹性缩窄与自隐式横向滚动条**：单个标签采用 `flex-1 basis-[196px] max-w-[220px] min-w-[116px]`，页签较多时优先均匀缩窄宽度；当总页签最小宽度之和超出标签条可用空间后，在标签条最底部自动启用 `.soxu-auto-scrollbar`（平时隐藏，悬停、聚焦或滚轮横向滚动时自动显现），同时右侧 `+` 新建对话按钮固定在滚动容器外不滚出；
   - 标签元素依次为：`[前置状态小圆点]` + `[代理标识]` + `会话标题` + `悬停显示 [归档] 与 [关闭 ×] 按钮`（使用语义 `role="tab"` 容器避免按钮嵌套）；
   - 支持逐个关闭全部标签页；当关闭最后一个标签时移除底部重叠输入框，居中铺满 `.soxu-dot-grid` 微点阵与微光引导首页（双几何 Soxu 矢量徽标 + `要做点什么？` + 即用圆角输入舱，输入首条消息自动创建无项目自由对话，底部附分诊台/工作树/历史快捷入口）；
   - **草稿保留不变量**：每个会话保留独立未发送草稿，切换或关闭前妥善防抖保存（`250ms`）。
2. **子代理委派轨道（Subagents Track，高 `28px`，仅当存在子代理时展开）**：
   - 当主 Agent 派生子代理时，在标签栏下方平滑展开一条 `#0D0D0D` 细轨，横向排列子代理胶囊：`[↳ research · 索引扫描 ✓ 12s]`、`[↳ codex · 协议单测 ⟳ 00:18]`。
   - 点击子代理胶囊可内联抽屉预览其流式日志；点击胶囊右侧 **「独立成页签 (Detach)」** 图标，可将该子代理提升为当前工作区的独立标签页继续追加人工提示，同时保留其父子溯源关系标签。

## 四、右栏：四合一上下文与审阅检视器（Context Inspector）

右栏顶部提供 4 个固定语义页签（支持拖拽排序，复用同一类型页签避免重复堆积）：

1. **`Diff`（实时工作树差异审阅）**：
   - 顶部工具栏：基准切换（`Uncommitted` vs `vs baseRef(origin/main)` vs `指定 Checkpoint`）、视图切换（Unified 单栏 / Split 双栏，宽 `< 480px` 时强制 Unified）、`/` 键快速过滤文件路径。
   - 支持一键打开 **Git 提交模态窗**：自动调用选定的轻量模型（如 `deepseek-v4.1-flash`）按仓库 `<emoji> <type>(<scope>): <中文描述>` 规范生成 Commit Message 草稿，并在提交前实时显示 `.githooks` 门禁预检状态。
2. **`Files`（零阻塞工作区文件树）**：
   - 目录遍历严格在后台线程执行，按 `token + workspace_path` 双重校验回填快照；点击转录区中的文件链接（如 `crates/soxu-protocol/src/lib.rs:42`）采用纯词法路径归一化（防止越界逃逸），自动展开右栏并高亮目标行。
3. **`Scripts`（`paseo.json` / 工作区受管脚本面板）**：
   - 列出 `daemon-dev`、`desktop-dev`、`mobile-dev`、`check-all` 等配置脚本，展示生命周期状态（`Running` / `Stopped` / `Exited(1)`）、监听端口徽章（如 `:7698`、`:5173` 一键打开预览）及启停控制键。
4. **`Terminal`（受控多窗格 PTY 终端）**：
   - 底色 `#050505`，支持水平/垂直分屏；Windows/Linux 下 `Ctrl+Shift+C` 复制、`Ctrl+C` 保留给进程 `SIGINT` 中断信号；支持断线后 `live / visible-snapshot` 恢复。

## 五、GPUI 键盘焦点上下文栈与全局快捷键矩阵

### 5.1 焦点上下文优先级栈（Focus Context Hierarchy）
为彻底消灭「按 `Esc` 关弹窗却误停后台 Agent」或「弹窗刚打开打字落入底层输入框」的经典桌面端 Bug，GPUI 键位绑定必须严格按以下从内到外的作用域隔离（内层处理后调用 `cx.stop_propagation()`）：

```text
ModalDialog (延迟 2 帧安全聚焦)
  ＞ CommandPalette ("Cmd+K", 输入非空时 Esc 先清空输入，再按关闭面板)
    ＞ AutocompletePopup ("@agent" / "/skill" / "#file"，必须在 Input 之后注册以接管上下键与 Enter)
      ＞ InlineRename ("SessionRename > TextInput"，Esc 仅取消重命名，绝不触发窗口级 Stop)
        ＞ ReviewDiff / ReviewDiffTree ("/" 聚焦过滤，方向键按树深度展开折叠)
          ＞ ComposerInput (Enter / Shift+Enter / Ctrl+Enter / Alt+Enter)
            ＞ WorkbenchGlobal (全局面板开关与会话切换)
```

## 七、轮次迷你导航轨（`ConversationNavigationRail`）与工作区标签/恢复机制

### 7.1 对话右侧轮次迷你刻线导航轨（对标 `padu/transcript_view.rs`）
当对话超过 2 轮时，在主对话滚动容器最右侧贴边浮动一条宽 `20px` 的迷你导航轨（`zIndex.rail = 15`，不挤占 `760px` 阅读列）：
- **刻度视觉规则**：每个用户+Agent 回合对应一条高 `3px`、宽 `10px`~`14px` 的水平微缩刻度线：
  - 普通已读轮次：`#383838`；当前可视窗口中的活跃轮次：加宽至 `16px` + **`#FFFFFF`**；
  - 含 `needs_input` 待审批轮次：琥珀 `#F59E0B`；含 `Checkpoint` 快照轮次：紫罗兰 `#A855F7` 点缀。
- **悬停气泡与点击跳转**：鼠标悬停任意刻线时，向左侧弹出宽 `240px` 的 `#262626`（`#383838` 边）浮窗，展示轮次号、前 48 字用户提问摘要及 Checkpoint 文件变更统计；点击后平滑滚动定位至该轮顶部。
- **GPUI 性能约束**：导航轨快照只通过 `Rc::ptr_eq(&self.turns, &other.turns)` 做 `O(1)` 指针相等性比较，禁止每帧深度遍历消息切片。

### 7.2 工作区彩色语义标签（Workspace Labels）与异常恢复卡
- **彩色标签**：对齐 `paseo` 工作区标签契约，左栏支持为 Worktree 附加精简语义小胶囊（如 `[契约先行]`、`[阻塞]`、`[待合并]`），圆点 `6px` + `11px` 文字，配色复用品牌/语义柔色底。
- **工作区恢复卡（Workspace Recovery）**：当用户在外部手动删除了 Worktree 目录导致 `path` 不存在或 `.git` 元数据损坏时，不在后台静默崩溃，而是在中栏顶部展示可执行恢复卡：提供 **`[从主仓重建 Worktree]`**（保留原历史聊天时间线，重新挂载对应分支）或 **`[仅以只读归档保留历史]`**。

## 八、Oryn / Codex / AGY 融合工作台增补规范

1. **左栏收件箱分诊入口与已置顶工作树**：
   - 左栏顶部置顶 **`收件箱 (Inbox)`** 按钮并聚合高风险待批 + `needs_input`/`failed`/`attention` 计数徽章，点击可将中栏原地切入 `InboxTriageView`（支持按状态/项目分组、一键批示或跳转回复、全部标为已读）；
   - 支持 **`已置顶` (`pinned`)** 星标工作区置顶区；运行中或待办工作树第二行展示当前工具意图（`activeIntent`）；
   - 所有左栏与页签行的悬浮辅助按钮改用 `.soxu-reveal-action`（触屏 `opacity: 0.88` 永不藏匿，鼠标悬停或激活项清晰可见）。
