## 一、对话流角色视觉层级（Pure Black Transcript Hierarchy）

消息流居中排布于 `#000000` 纯黑画布之上，阅读列最大宽度 `760px`，轮次间垂直间距 `24px`（`--soxu-space-6`）：

1. **用户消息（User Turn）—— 右对齐 `#212121` 胶囊**：
   - 复刻 ChatGPT 经典布局：靠右对齐，最大宽度 `78%`（不超过 `560px`），背景 `--soxu-surface-raised` (`#212121`)，圆角 `18px`（多行）或 `9999px`（单短句），内边距 `10px 16px`，文字 `#ECECEC`。
   - 若该消息是通过运行中 **`Steer`（中途纠偏）** 注入的，气泡右上角附带电光蓝微标 `[⚡ 中途纠偏 · 已在第 3 步注入]`，并在原 Agent 回复流中精确切开上下文位置。
2. **Agent 回复（Assistant Turn）—— 无气泡全宽左对齐**：
   - 直接排布在 `#000000` 画布上，零背景框干扰，最大化代码与长文阅读舒适度。
   - 顶部紧凑身份头（高 `22px`）：`[CLI 矢量小图标 16px]` + **`codex`** (`#ECECEC` `600`) + `gpt-6.2-sol · high` (`#8E8E8E` `12px`) + 右侧悬停显现操作簇（复制全文、分叉会话、跳至本轮检查点）。
   - 代码块（Fenced Code Block）：背景 `#0D0D0D`，外框 `1px solid #262626`，圆角 `12px`；顶栏高 `32px`（底色 `#171717`），左侧显示语言名与相对文件路径，右侧常驻 `[复制]` 与 `[应用到文件]` 按钮。
3. **折叠思考窗（Live Reasoning Window）**：
   - **流式思考中**：单行高 `30px` 紧凑脉冲条，`[🧠 正在推演架构边界... 03.4s]`，尾部预览实时滚动的最后一段思考摘要（严格按 UTF-8 字符边界切片，防止多字节中文 panic）；
   - **思考完成后**：自动收起为一行低调的 `#8E8E8E` 可点击折叠头 `▸ 已深度思考 6.8 秒`（展开后左侧带 `2px` `#262626` 竖向引导线，文字采用 `#B4B4B4` `13px`）。

## 二、5 类结构化工具调用卡片（Structured Tool Call Cards）

拒绝刷屏式原始 JSON 倾泻。连续发生的同类轻量只读工具自动折叠成「活动组（Activity Group）」，写操作与命令执行独立成卡（背景 `#171717`，描边 `1px solid #262626`，圆角 `12px`）：

| 工具类别 | 折叠态单行展示（高 `34px`） | 展开态核心内容 | 状态与边界规则 |
| :--- | :--- | :--- | :--- |
| **1. 只读探索聚合组**<br>(`Read` / `Search` / `Glob`) | `▸ 🔍 已检索并读取 6 个文件 (aoci.code.txt, lib.rs...) · 0.4s` | 紧凑相对路径清单（剥离工作区前缀）与命中行数，点击路径直接在右栏打开对应行 | 连续只读调用自动合并为 1 行，避免打断推理主线阅读 |
| **2. 文件编辑与新建**<br>(`Edit` / `Write` / `Patch`) | `▾ ✏️ 修改 crates/soxu-magpie/src/lib.rs (+24 -5)` | 内联语法高亮 Unified Diff 预览；单卡最多直接渲染 **`400` 行**，超出部分显示 `[展开剩余 128 行隐藏差异]` 并在右栏完整打开 | 展开快照仅在点击时构建一次，严禁在虚拟列表逐帧渲染中重复解析 |
| **3. 终端命令执行**<br>(`Bash` / `PowerShell`) | `▸ ❯ cargo test --workspace · ✓ 退出码 0 · 2.1s` | `#050505` 终端黑匣子（等宽 `13px`），支持 ANSI 16 色语义映射；失败（退出码 `≠ 0`）时自动默认展开末尾 25 行错误输出并以绯红徽章标记 | 运行中实时显示耗时秒表与 `[终止命令]` 快捷操作 |
| **4. MCP 工具调用**<br>(`aoci_*` / `codegraph_*` 等) | `▸ 🔌 aoci · aoci_maintain [Direct 工作区] · ✓ 0.3s` | 分节结构化键值表（优先解析 `structuredContent`，屏蔽冗长系统内部字段）+ 路由来源标签（`Magpie Shared` 或 `Direct Workspace`） | 清晰区分全局共享 MCP 与当前 Worktree 专属索引 MCP |
| **5. 子代理委派卡**<br>(`Subagent` / `Handoff`) | `▾ 🤖 委派 pi (deepseek-v4.1-flash) · 巡检文档链接 · ⟳ 运行中` | 实时滚动子代理最近 3 条工具活动摘要 + 右上角 `[独立成页签 ↗]` 与 `[打开对话]` | 子代理产生待审批请求时，卡片边框同步升级为琥珀呼吸态 |

## 三、双端实时同步权限审批卡片（Permission Gate Card）

权限审批是桌面工作台与手机遥控端最核心的协同触点，必须在纯黑背景下一眼捕获视线且绝不误触：

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ ┃ 🛡️ 需要人工授权 · Bash 命令执行                     [工作区: feat/m2-cli]  │
│ ┃ ────────────────────────────────────────────────────────────────────────── │
│ ┃ ❯ git clean -fdX temp-fixtures/                                            │
│ ┃ ⚠️ 命中文件清理规则：将删除受忽略的临时测试产物，影响范围限于当前 Worktree │
│ ┃                                                                            │
│ ┃ [拒绝并指导修改]          [本会话允许同类只读/测试]        [ 允许一次 ↵ ]  │
└──────────────────────────────────────────────────────────────────────────────┘
```

1. **风险分级视觉编码**：
   - **常规写外围 / 网络 / 普通命令审批**：卡片底 `#171717`，左侧 `3px` 琥珀金边条 `#F59E0B`，外描边 `rgba(245, 158, 11, 0.38)`；
   - **命中高危破坏性红线（如 `rm -rf`、`Remove-Item -Recurse`、`git push --force`、修改 `~/.config/magpie` 等）**：左侧升级为 `3px` **绯红边条 `#EF4444`**，外描边 `rgba(239, 68, 68, 0.45)`，附带醒目的绯红风险横幅，且**自动禁用「本会话始终允许」按钮，默认键盘焦点停留在「拒绝并指导修改」上**，强制人工审慎确认！
2. **拒绝并附带反馈（Reject with Guidance）**：
   - 点击「拒绝并指导修改」时，卡片底部原地展开单行输入条（如输入 `"改用 tempfile::TempDir，不要清理真实目录"`），Agent 收到结构化拒绝原因后立即在同一轮内自我修正，无需中断重来。
3. **跨设备毫秒级幂等消解**：
   - 桌面端与所有已配对手机 PWA 共享同一个 `approval_id` 状态。当用户在手机上点击「允许一次」后，桌面端卡片在 `100ms` 内无抖动收拢为单行审计记录：`✓ 已批准执行 (由 iPhone 遥控端 确认 · 22:41:08)`，防止两端重复点击冲突。

## 四、Git 对话轮次检查点与安全回退（Turn Checkpoint & Rewind）

每当一个对话轮次（Turn）产生了工作树文件变更，`soxu-git` 自动生成轻量级快照引用（`CheckpointSummary`），并在该轮回复末尾渲染一条极简检查点锚点横条：

```text
─── ⊶ 检查点 #04 · commit 7c4e91a · 变更 4 个文件 (+86 -14) ─── [查看本轮 Diff] [回退至此轮 ↺] ───
```

- **锚点样式**：居中细横线贯穿，中间嵌高 `26px` 的 `#121212` 胶囊（描边 `#262626`，图标采用 `--soxu-semantic-handoff` `#A855F7`），平时低调不抢戏，悬停时亮起操作按钮。
- **点击 `[回退至此轮 ↺]` 弹出安全三选一确认框**（绝不静默覆写工作树）：
  1. **仅分叉对话（保留当前磁盘代码不变）**：从第 #04 轮处新建对话分支重新提问；
  2. **仅回退工作树代码至 #04 快照（保留后续对话记录供参考）**：回退前自动将当前未提交修改保存为备份恢复点（Safety Stash Ref），随时可一键撤销回退；
  3. **代码与对话同步回退至 #04**：完整时光倒流（同样自动创建隐藏备份引用保底）。

## 五、第 6 类核心交互卡：`PendingUserInput` 结构化提问卡（对齐 `padu` / `ask_question`）

当原生 CLI 发起结构化选择题（单选或多选 + 补充自由输入）时，渲染位置高于三态输入舱、与权限审批卡同级：
- **视觉规范**：底色 `--soxu-surface-card`（`#171717`），左侧 `3px` 蓝色或翠绿竖条（区别于权限审批的琥珀/绯红警示），圆角 `12px`，头部展示问题进度（如 `问题 1 / 2 · 需你确认架构选型`）与简洁提问正文。
- **选项按钮网格**：每个选项独立一行（`min-height: 36px`，移动端 `44px`），首行推荐项带翠绿微标 `[推荐]`，右侧支持键盘数字 `1-9` 快选微标；点击选项立即高亮边框并勾选。
- **自定义回答与提交**：选项列表下方提供「或补充其他说明...」单行输入框；支持 `Enter` 提交当前选择，多题时底部出现 `[上一题]` / `[下一题 →]` 与最终 `[确认提交全部回答]` 纯白主 CTA 按钮。
