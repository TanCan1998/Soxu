## 一、首次启动三步引导向导（非默认常驻）

仅当全新环境首次启动（`has_completed_onboarding == false`）时按需弹出，**主界面与左栏底部不保留任何常驻引导按钮或入口**（若已完成仅可在独立设置弹窗「快捷键与关于」分栏中按需重新触发）；向导居中宽 `560px`（移动端自适应 `92vw`），纯黑底色 `#171717`，描边 `1px solid #383838`，圆角 `18px`，顶部 3 段进度条，全程允许右上角 `[跳过引导]`：

1. **Step 1 · 本机生态零破坏自检**：
   - 自动展示 `soxu-magpie` 与 `soxu-drivers` 探测结果：
     - Magpie 状态卡（`MagpieManaged` 翠绿高亮 / `StandaloneNative` 中性提示）；
     - 7 大原生 CLI 可用绿灯清单（自动隐藏未装 CLI）；
     - 显式承诺横幅：`「Soxu 只读读取已有配置与历史，绝不篡改 ~/.claude / ~/.codex / ~/.pi / ~/.config/magpie」`。
2. **Step 2 · 绑定首个 Git 项目与 Worktree 隔离**：
   - 三选一快速按钮：「选择本地目录」、「克隆 GitHub 仓库」或「新建并初始化 Git 仓库」；
   - 告知已启用共享编译缓存提示（`CARGO_TARGET_DIR` 跨 Worktree 共享免重复编全量 Rust）。
3. **Step 3 · 手机遥控与快捷键速览**：
   - 内嵌实时生成的局域网 / 中继配对二维码预览（`http://<ip>:7698/#offer=...`）+ 5 个最常用快捷键卡片；
   - 点击 `[开始使用 Soxu]` 立即写入 `has_completed_onboarding = true` 并落盘。

## 二、窗口级 `Cmd/Ctrl + K` 全局命令面板（Command Palette）

> 对标 `padu/command_palette.rs` 零闪烁、零渲染 I/O 设计。

- **几何规范**：宽 `640px`、最大高 `440px`、顶距视口 `12vh`、底色 `--soxu-surface-floating` (`#262626`)、外框 `1px solid #383838`、圆角 `16px`。
- **三段垂直骨架**：
  1. **搜索输入区（高 `52px`）**：始终保持真实输入焦点（即使上下方向键在移动列表选中光标，光标闪烁也不触发全表重算）；全文历史检索带 `90ms` 后台防抖与 24 条 LRU 缓存；
  2. **分区结果列表**（分区头高 `26px`，大写 `#8E8E8E`）：按固定顺序排列 **`推荐动作 (Suggested)` → `活跃工作区与会话 (Sessions)` → `工作区文件与代码符号 (Files)` → `原生 CLI 历史 (History)` → `设置与命令 (Commands)`**；常规行高 `40px`，带摘要行 `54px`，文件结果行 `48px`；
  3. **底部键位提示栏（高 `36px`，底色 `#171717`）**：`↑↓ 选择` · `↵ 执行` · `⇥ 分区跳转` · `Esc 清空/关闭`。
- **双段 `Esc` 隔离逻辑**：输入框有文字时按 `Esc` 仅清空搜索框并留存焦点；输入框为空时再按 `Esc` 关闭面板并还原原焦点。

## 三、扫码配对、AI 提交预览与工作区添加弹窗

### 3.1 手机端配对弹窗（Mobile Pairing Modal）
- **左半区**：高对比度纯白底衬托的居中二维码矩阵（带安全留白 Quiet Zone ≥ `16px`，外框圆角 `12px`，确保任何光线下的手机相机毫秒级对焦），上方切换 `[局域网直连 (192.168.x.x:7698)]` / `[加密中继通道]`。
- **右半区**：6 位一次性数字配对码（等宽 `24px` 粗体、`letter-spacing: 0.16em`）+ 倒计时刷新环（5 分钟失效防泄露）+ 已配对设备在线管理列表（支持一键吊销单台旧手机令牌）。

### 3.2 结构化 Git 提交编辑弹窗（Commit Dialog）
- 弹窗容器内边距严守 `24px`（`p-6`），各表单区块垂直间距 `16px–20px`（充裕呼吸感）；
- 复选框待提交文件变动列表（支持单文件取消勾选与内联行统计 `+28 -4`）；
- **拆分式首行构建条**：
  1. **图标与提交类型快速选择按钮 / 面板**：提供 `✨ feat`、`🐛 fix`、`💄 ui`、`♻️ refactor`、`📝 docs`、`🔧 chore`、`⚡ perf`、`✅ test` 一键点选；
  2. **提交范围（括号内）组合选择器**：左侧下拉或快选按钮预设范围（`无范围`、`drivers`、`core`、`desktop`、`mobile`、`protocol`、`git`、`design`、`ci`），右侧紧接可编辑输入框支持自定义任意模块范围名称；
  3. **简述编辑框** + 实时合成预览条（直观显示完整首行 `<emoji> <type>(<scope>): <简述>`）；
- **多行正文 `<textarea>` 编辑框**（用于撰写详细变更动机与 `Refs #<issue>`）+ 顶部 `[智能生成草稿]` 辅助键；
- **提交前隐私与规范门禁栏**：实时提示 `Emoji 格式合规`、`无个人路径泄露`、`密钥扫描通过`。

### 3.3 添加项目三合一模态（Open / Clone / Init Project）
- 顶部三选项卡：`[打开现有目录]` / `[克隆 GitHub 仓库]` / `[初始化新仓库]`；
- 打开非 Git 普通目录时自动提示「是否立即执行 `git init` 以解锁 Worktree 多路隔离并行？」，点击即可一键升级项目类型。

## 四、Schedules & Heartbeats 自动化调度中心

左栏专属入口进入自动化调度全屏/独立子视图（不挤压主聊天区域）：

1. **双引擎分栏清晰区隔（对齐 `paseo` 语义）**：
   - **Schedules（定时新建隔离代理）**：按 Cron（如 `0 2 * * *` 或 `*/30 * * * *`）自动创建干净会话/Worktree 执行巡检、文档同步或依赖检查；显示 `触发 Cron` + `时区` + `指定 Agent/Model` + `最大运行次数 / 过期时间` + `历史运行日志`（含单次 `[▶ 立即测试运行]` 与 `[⏸ 暂停]`）。
   - **Heartbeats（周期唤醒汇报守护）**：轻量周期提醒注入指定活跃会话，用于 CI 守候、PR 检查跟踪与长程任务防停滞汇报（遵循「修改 cadence 需重建而非覆盖历史运行流」模型）。
2. **未读失败角标与状态归属**：自动化任务产生的异常退出会统一累加至左上角与移动底部导航栏的 **绯红失败数字角标**；查看对应运行日志详情后自动消解未读标记。

## 五、模态框焦点捕获、几何常量与边界处理表

为符合 WCAG 2.2 焦点可见与防遮挡准则，所有全局模态弹窗与抽屉必须遵守以下统一契约：

| 模态 / 子页面 | 宽高与圆角规范 | 首帧焦点与键盘隔离 | 空态 / 错误 / 取消行为 |
| :--- | :--- | :--- | :--- |
| **Onboarding 向导** | `w = 560px`, `p(20)`, `rounded(18)` | 打开聚焦「下一步」主按钮；允许 `Esc` 跳过 | 即使无网络或无 Magpie 也必须完整通过 Step 1，不能卡死起步流程 |
| **`Cmd+K` 命令面板** | `w = 640px`, `max-h = 440px`, `rounded(16)` | 搜索框 `52px` 恒定持焦；列表光标通过 `Ctrl+N/P` 与 `↑↓` 驱动 | 搜索无结果时展示 `160px` 空态卡并提示关键词修正或一键新建会话 |
| **手机扫码配对弹窗** | `w = 580px`, `p(20)`, `rounded(18)` | 打开聚焦「刷新配对码」；QR 区四周留白 ≥ `16px` | 局域网无可达非回环 IP 时自动高亮提示切换到中继模式或复制手动连接地址 |
| **Git Emoji AI 提交** | `w = 540px`, `max-h = 80vh`, `rounded(18)` | 延迟两帧聚焦提交消息框，防 `Enter` 误透传 | 提交门禁（Emoji 格式 / 个人路径 / `.gitleaks`）任意失败时禁用「立即提交」并用绯红框高亮具体违例行 |
| **Checkpoint 回退窗** | `w = 480px`, `p(20)`, `rounded(18)` | 默认聚焦安全的「仅分叉对话」或「取消」按钮 | 回退失败或存在冲突文件时展示可执行 `git status` 恢复指引，已建好的 Safety Stash 绝不删除 |
| **Schedules 自动化看板** | 右主区全幅限宽 `960px`，卡片 `p(14)` | Tab 键按 Cron → 暂停开关 → 运行日志顺序遍历 | 无任何定时任务时展示空态引导卡片与 3 个常用模板（每日巡检、CI 守候、周末 AOCI 校准） |

### 5.1 自动化任务创建表单字段约束
- **间隔表达方式**：支持预设频率胶囊（每 15 分钟 / 每小时 / 每日凌晨 02:00）与标准 5 段 Cron 表达式实时人类可读预览（如 `0 2 * * *` → `每天 02:00 (Asia/Shanghai)`）。
- **最小影响保护**：所有无人值守运行的 `Schedule` 默认采用 **新建隔离 Git Worktree + `Ask/Auto-Edit` 受限沙箱策略**，禁止在无人值守下自动开启无保护强推。

### 5.2 添加项目（Open / Clone / Init）三合一校验与实时反馈
- **打开现有目录**：选择路径后后台实时探测 `.git`、是否存在 `mise.toml` 与 `paseo.json`、以及该仓库下历史原生 CLI 会话数量（展示微标签 `探测到 4 个历史 Claude/Codex 会话`）。
- **克隆 GitHub 仓库**：输入 URL 或 `owner/repo` 时自动按 `git-remote` 规则归一化预览完整 SSH/HTTPS 地址，克隆进度流内置于弹窗下方 `#050505` 折叠日志条，不关闭窗口即可发现并重试认证失败。
- **新建并初始化**：输入项目名实时校验目录名合法性，勾选「自动生成推荐 `.gitignore` 与 `AGENTS.md` 骨架」可在初始化首屏直接为新项目启用 Soxu 治理模式。

### 5.3 自动化运行日志与失败归因展示
- 每次 `Schedule` 执行完毕后生成只读运行切片记录，按 `开始时间`、`耗时`、`退出码`、`关联 Worktree 分支` 与 `产出 PR/Checkpoint` 紧凑排版；
- 若某次定时运行发生工具权限阻塞或脚本失败，列表右侧立即亮起绯红 `[未读失败]` 胶囊并同步推送桌面/移动推送通知，点击运行卡片进入详情日志流后即时将未读态清零（历史记录保留失败状态供追溯）。
