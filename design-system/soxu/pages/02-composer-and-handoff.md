## 一、ChatGPT 纯黑悬浮输入舱（Composer）几何与光学规格

```text
┌─ 待发队列条 (仅当 Queue 队列非空时展开, #171717 底, 顶圆角衔接) ───────────────────────┐
│ ⏳ 排队中 (1): "跑完单元测试后顺便更新 docs/ops/PROGRESS.md"   [提级为纠偏 ⚡] [编辑] [×] │
├────────────────────────────────────────────────────────────────────────────────────────┤
│  [@codex ▾] 请检查 crates/soxu-magpie/src/lib.rs 的降级分支边界...                     │
│                                                                                        │
│  [＋]  [⌘ pi ▾] [⚡ Magpie · gpt-6.2-sol ▾] [🧠 medium ▾] [🛡️ Ask ▾]    [纠偏 ▾] [ ↑ ] │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

- **外框容器与同步宽度对齐铁律**：输入框外层必须与上方对话消息流同置于同一滚动居中容器内（共同遵循 `--soxu-layout-transcript-max-width` / `--soxu-layout-composer-max-width` = **`760px`**，左右内边距完全相等）。拖拽调整左栏或右栏宽度时，输入舱与上方对话气泡/工具卡须按完全相同的像素宽度实时同步伸缩；背景色 `--soxu-surface-composer` (`#212121`)，圆角 `22px`（`--soxu-radius-composer`），常态描边 `1px solid #2E2E2E`，聚焦态 `1px solid #424242`。
- **多行文本编辑区**：
  - 最小高度 `44px`（单行舒适态），随内容自动增高至最大高度 `220px`（桌面端） / `140px`（移动端），超出后内部启用细滚动条；
  - 桌面字号 `14px`（行高 `21px`），移动 Web 字号强制 `16px`（行高 `22px`）；
  - UTF-16 光标与选区安全处理，支持直接粘贴剪贴板截图、拖拽代码文件或选择右侧 Diff 行区间作为结构化上下文芯片（Context Chip）挂载在文本区上方。

## 二、四态回合投递状态机（Idle / Preparing / Running: Queue · Steer · Interrupt）

在 Agent 正在思考或连续调用工具的几分钟内，**绝不允许锁死或置灰输入框**。Soxu 将 `soxu-protocol::ActiveTurnBehavior` 完整映射为直观的视觉状态机：

| 当前会话运行态 | 输入框内容状态 | 主按钮图标与颜色 | 快捷键绑定 | 语义行为与边界回退保护 |
| :--- | :--- | :--- | :--- | :--- |
| **`Idle`（空闲）** | 空 | 禁用上箭头（`#2A2A2A` 底 / `#666666` 标） | — | 不可提交 |
| **`Idle`（空闲）** | 非空 | **纯白实心圆 + 纯黑上箭头 `↑`** (`#FFFFFF` / `#000000`) | `Enter` 提交<br>`Shift+Enter` 换行 | 开启新对话轮次（`turn_index + 1`） |
| **`Preparing`（启动工作树/进程中）** | 任意 | 旋转加载环 + 停止方块（优先于 Busy 判定） | `Esc` 取消准备 | 后台正在挂载 Worktree 或拉起 CLI 子进程，防止重复派发 |
| **`Running`（运行中）** | **空** | **纯白实心圆 + 纯黑停止方块 `■`** | 双击 `Esc` 或点击按钮 | 立即向当前 CLI 驱动发送优雅中断信号（SIGINT / Cancel Turn） |
| **`Running` · `Queue`（默认排队模式）** | **非空** | 琥珀边框胶囊 `[排队 ▾]` + 纯白上箭头 | `Enter` 入队 | 消息不打断当前推理，立即进入顶部「待发队列条」；当前回合一结束自动发出 |
| **`Running` · `Steer`（中途纠偏模式）** | **非空** | **电光蓝描边 `#3B82F6`** + 蓝色闪电发送键 `⚡` | `Ctrl/Cmd + Enter` 直接纠偏 | 在当前回合的下一个工具边界实时注入指令。**降级透明原则**：若当前 CLI 驱动不支持热注入（如单次 `--print` 模式），胶囊自动显示微提示 `↻ 将中断并带上下文续接`，且若回合在读取前意外终止，未消费的 Steer 消息自动退回输入框草稿，**绝不静默丢失**！ |
| **`Running` · `Interrupt`（打断重发模式）** | **非空** | **绯红描边 `#EF4444`** + 红色打断重发键 `⏹↑` | `Alt + Enter` | 立即终止当前正在执行的回合，并用输入框中的新指令开启全新回合 |

### 2.1 待发队列条（Queued Message Strip）交互
- 当存在 `Queue` 消息时，在输入舱顶部展开高 `34px` 的队列条（底色 `#171717`，描边 `#262626`）。
- 如果用户发现 Agent 正在往错误方向越走越远，无需重新打字，只需点击队列条右侧的 **`[立即纠偏 ⚡]`**，即可一键把已排队的 `Queue` 消息实时提级为 `Steer` 或 `Interrupt`（避免重发导致消息被读两次）。

## 三、底部常驻控制栏（不折叠权限）与按 Agent 动态适配规则

参考 Agy 桌面端极简高效的直觉交互：**操作权限档位（Ask / Auto-Edit / Plan 等）绝不隐藏进折叠菜单，必须与代理、模型、思考强度一起常驻于输入舱左下控制栏**，同时输入框右下紧邻发送键放置**上下文窗口使用百分比小圆环**：

1. **Agent CLI 驱动选择器 `[pi ▾]`**：
   - 列出本机可用驱动：`codex`、`claude`、`pi`、`agy`、`opencode`、`copilot`、`qwen`。
   - 切换代理时立即调用能力协商矩阵，自动将模型、权限档位、思考等级及运行中投递行为同步调整至目标代理支持范围内（例如不支持思考调节的 `copilot` 自动隐藏思考档位；`agy` 切换权限档位为规划确认/询问执行/自动编辑/自主运行）。
2. **模型与路由源选择器 `[gpt-6.2-sol ▾]`**：
   - 根据当前选定代理实时过滤支持模型列表；在 Magpie 协同态下按能力分层展示并支持模糊检索。
3. **思考等级选择器 `[中 ▾]`（全中文分级：`低 / 中 / 高 / 极高 / 最高`）**：
   - 仅当所选代理与模型均支持思考强度调节时显示；切换模型后若当前档位不被支持，自动向默认合规档位降级并在左下角轻提示。
4. **常驻执行权限档位选择器（参考 Agy 桌面端，绝不折叠）**：
   - 常驻在工具栏显著位置，带语义色点与纯中文档位名：
     - `codex`：`只读分析` / `询问确认` / `自动写入` / `完全授权`
     - `claude`：`只读规划` / `每次询问` / `自动接受编辑` / `跳过常规确认`
     - `agy`：`规划确认` / `询问执行` / `自动编辑` / `自主运行`
     - `pi`：`每次询问` / `自动编辑` / `工作树全权`
     - `opencode` / `copilot`：按实际能力收缩至 2~3 档。
5. **输入框左侧 `+` 更多操作与可移除标签芯片（参考 Agy 桌面端）**：
   - 在左下控制栏最左侧放置圆形 `+` 号按钮，提供上下文引用（源码片段、目录、`Git Diff`、最近终端输出、图片/本地文件上传）与快捷技能指令（`/plan`、`/review`、`check-all`）；
   - 所有添加项与跨代理移交目标（`@agent`）统一在文本区正上方渲染为结构化胶囊标签芯片（Chips），支持单独移除并在提交时随消息气泡附带发送。
6. **三色上下文窗口圆环与「会话统计」详单浮层**：
   - **三色上下文圆环（`ContextUsageRing`）**：按已用比例动态呈现既有主题三档语义色：**绿色（`< 65%`）**、**琥珀黄（`65% – 88%`）**、**绯红色（`>= 88%`）**，精度保留一位小数（如 `86.4%`）；
   - **会话统计胶囊与浮层（`SessionStatsPopover`）**：紧邻圆环右侧显示速度胶囊（时钟图标 + 绿色 `tok/s` 读数），点击展开详单浮层，包含：轮次/步数、累计 Token、API 参考费用、平均/峰值/最近速度、缓存命中、缓存观察，以及可折叠展开的 `更多统计`（模型用时、工具用时、首 Token 延迟），且遥测文本严格禁止使用中圆点分隔符。

## 四、`@agent` 跨代理移交（Handoff）与自动补全弹层

当用户在输入框键入 `@`、`/` 或 `#` 时，在输入舱正上方 `8px` 处锚定弹出浮层（`--soxu-surface-floating` `#262626`，`1px solid #383838`，最高展示 8 行，每行 `34px`）：

1. **`@` 跨 Agent 提及与上下文移交（Handoff）**：
   - 输入 `@codex`、`@pi` 或 `@agy` 选择目标 Agent 后，输入框生成紫罗兰色胶囊 `@codex`（`--soxu-semantic-handoff-soft` 底 + `#A855F7` 字），并在右侧浮现移交范围微开关：
     - `[✓ 附带最近 3 轮结论摘要]`
     - `[✓ 附带当前工作树未提交 Diff 路径 (3 files)]`
     - `[○ 在新建独立 Worktree 中启动]`
   - 发送后，Soxu 自动在目标 Agent 中建立新会话（或投递至同工作区已有目标会话），并在原会话与目标会话的时间线中同时插入可双向点击跳转的 **「⇄ 会话移交锚点卡」**。
2. **`/` 技能与命令补全（Skills & Slash Commands）**：
   - 聚合当前工作区 `.agents/skills`、Magpie `routed/direct` 技能及内置快捷动作（`/compact`、`/checkpoint`、`/review`、`/handoff`），全部由后台执行器预热缓存，击键过滤纯内存 `0 I/O` 完成（耗时 `< 1ms`）。
3. **`#` 工作区文件与符号引用**：
   - 接入高速文件索引与 CodeGraph 符号检索，选中后插入紧凑文件芯片 `[📄 soxu-magpie/src/lib.rs:12-45]`。

## 五、上下文附件芯片、`lost-controls` 回退提示与移交溯源卡细节

### 5.1 附件与代码行引用芯片（Context Chips）像素解剖
在文本输入区正上方横向排列（自动换行，`gap: 6px`，`pb: 6px`）：
- **代码文件/行区间芯片**：高 `26px`、圆角 `8px`、底 `#171717`、描边 `1px solid #2E2E2E`，左侧文件类型小图标（`14px`）+ 等宽 `12px` 相对路径及行号（如 `crates/soxu-drivers/src/lib.rs:18-46`）+ 右侧 `16×16px` 移除 `×` 键。
- **图片/截屏附件缩略卡**：高 `44px`、宽最大 `160px`、圆角 `10px`，左侧 `34×34px` 圆角 `6px` 缩略图（点击放大预览）+ 文件名与字节大小 + 右上移除按钮。
- **草稿持久化守则**：所有输入文本与附件列表均按 `(workspaceId, sessionId)` 做 `250ms` 防抖异步落盘并附单调 `generation` 版本号；切换会话时恢复草稿 **禁止同步执行 `fs::stat`**，若发送时发现文件已不存在再弹出友好提示。

### 5.2 模型切换失效参数回退提示（`lost-controls` Recovery，对齐 `paseo`）
- 当用户在已有设置（例如 `Codex + gpt-6.2-astra + thinking: xhigh + fast_mode: true`）下切换到另一个模型或 CLI（例如 `Pi + deepseek-v4.1-flash`）时，后者可能不支持 `xhigh` 或 `fast_mode`：
  - 系统自动保留新模型支持的控制项，将失效参数回退至新模型默认值，同时在输入舱左下胶囊栏上方轻轻浮现一条高 `24px` 的非阻塞自消退提示条：`ⓘ 已因切换至 deepseek-v4.1-flash 自动调整不支持的思考档位 (xhigh → medium)`（持续 `3.5s`）。

### 5.3 跨 CLI 移交双向溯源卡（Cross-CLI Handoff Card）
当 `@codex` / `@pi` 移交触发后，时间线中不单单出现普通文本，而是在**源会话末尾**与**目标会话开头**各插入一张紫罗兰描边（`rgba(168, 85, 247, 0.32)`）双向锚点卡：
- 源会话端：`⇄ 已将上下文移交至 codex · gpt-6.2-sol（附带 3 轮摘要 + 2 个变更文件）  [跳转至目标会话 ↗]`
- 目标会话端：`⇄ 承接自 pi · claude-sonnet-5.5 的移交上下文  [展开前序摘要]  [回到源会话 ↙]`
