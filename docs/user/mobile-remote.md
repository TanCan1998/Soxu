# 移动端远程查看与控制指南

Soxu 采用守护进程内置响应式 Web/PWA 方案（无需应用商店审核上架），让你在离开电脑时通过手机浏览器或主屏幕 PWA 实时掌控桌面端的多 Agent 工作区。

---

## 1. 核心能力

1. **实时会话监控**：查看各项目与 Git Worktree 下活跃 Agent 的流式输出、当前执行工具与耗时；断网或锁屏唤醒后自动按事件游标增量追平。
2. **高危操作与权限审批**：当桌面端 Agent 请求执行敏感终端命令或越界文件操作时，在手机端一键点击「批准」或「拒绝并附原因」。
3. **中途指令干预（Queue & Steer）**：
   - **排队（Queue）**：追加后续任务，等当前轮次完成后自动接续；
   - **纠偏（Steer）**：不打断整体上下文，在下一步注入修正提示词；
   - **中断（Interrupt）**：立即停止当前轮次并转向新指令。
4. **简要 Diff 与托管脚本启停**：快速浏览当前工作区修改的文件 Diff，按需启停 `paseo.json` / 工作区托管开发脚本。

---

## 2. 安全连接方式

- **局域网 / Tailscale 直连**：在家庭/办公同网段或个人 Tailscale 组网下，直接在桌面端点击「移动设备配对」，用手机扫描一次性配对二维码获取设备鉴权令牌并添加到手机主屏幕。
